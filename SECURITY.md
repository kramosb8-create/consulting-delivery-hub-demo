# Seguridad

- No almacenar credenciales, tokens, `.env` reales ni contraseñas.
- Usar GitHub Secrets para credenciales de CI/CD.
- Los datos del demo son ficticios/representativos y no contienen información sensible.
- En proyectos de clientes, definir repositorios privados y acceso por mínimo privilegio.
- Revisar dependencias y alertas de seguridad antes de liberar versiones.
